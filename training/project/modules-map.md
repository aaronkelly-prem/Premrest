# Modules — the locked map

The agreed list. Streams carry sequence; prerequisites carry gating. Status is whatever exists — a module is "drafted" when its folder holds a script + test + practical checklist.

**Accreditation tiers:** **Core** = every tech must hold it. **Specialist** = an added stamp, issued by need (new hires) or swept up in the refresh (existing staff).

## Build order (recommended)

Foundations spine first — it gates everything and both tracks need it: **1 → 2 → 3 → 4 → 5 → 6 (flagship)**. Then specialist stamps in demand order (Tile & Grout and Carpet Spotting tend to be first-asked). Confirm before scripting.
