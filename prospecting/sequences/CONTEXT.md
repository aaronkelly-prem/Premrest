# sequences — formalised outreach campaigns

Reusable outreach sequences the drafting stage (`../03_draft-outreach/`) picks from. A sequence is a named, repeatable series of touches toward one kind of target, so outreach stops being ad hoc.

## Deliberately thin for now

Outreach today is ad hoc. The plan (handover section 8) is to **run sequences in this workspace for a month or two and let the real shape emerge from actual runs**, then hand a battle-tested spec to Ben for a Pulse module — not to guess the sequences up front. So this folder starts with the shape, not finished campaigns. Build each sequence out as its first real run teaches it.

## Sequence shape (copy this when building one)

```
# {sequence-name} — {target}
Goal: {the partnership outcome this sequence is aiming at}
Touches:
  1. {channel} — {purpose} — {timing}
  2. {channel} — {purpose} — {timing: e.g. +5 business days if no reply}
  3. ...
Proof to lean on: {the kind of Nick-traction evidence that fits this target}
Voice notes: peer-to-peer partnership, per ../../_shared/voice.md
```

Each sent step becomes a loop with the next step as its next action (`../04_review-send-log/CONTEXT.md`).
