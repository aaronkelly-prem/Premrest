# 03_draft-outreach — draft the partnership approach

One job: write a full, ready-to-send partnership outreach to the confirmed exec.

## Inputs
- Working (this run): ../02_find-contact/output/contact-{firm}.md
- Working (this run): ../01_spot-concentration/output/candidates-{date}.md (Nick's traction at this firm — the proof)
- Reference (every run): ../../_shared/voice.md
- Reference (every run): ../sequences/CONTEXT.md (pick the sequence/campaign this outreach belongs to)

Do NOT load: Pulse pricing/quote detail, other firms' drafts.

## Process
1. Choose the sequence this approach belongs to (see `../sequences/`).
2. Draft a **peer-to-peer partnership approach, not a service pitch** — a GM inviting an exec into a partnership, leaning on Nick's existing traction as proof.
3. Follow `voice.md` exactly: no em dashes, no AI-sounding language, Australian English, direct.
4. Write the **full email**, ready to send. Not bullets, not an outline.

## Outputs
- draft-{firm}.md → output/  (subject line + full email body, plus which sequence step this is)

## Human check
Aaron reads the full draft and edits in place. The next stage sends whatever he leaves here. This is the heaviest gate in the pipeline — nothing becomes an email without his review.
