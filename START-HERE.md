# Start here (human setup)

Plain-English notes for Aaron on getting this workspace onto your Mac and open in Claude Code. This file is for you; Claude itself starts from `CLAUDE.md`.

## What this is

Your Premrest workspace: the single home for everything Premrest — prospecting, ops, calendar, email, team, podcast, and finishing what gets started. It is walled off from all personal and other-business work.

## Get it onto your Mac (one time)

A "workspace" in Claude Code is just a folder on your Mac. This folder currently lives in your GitHub repo (`aaronkelly-prem/Premrest`). Copy it down once:

1. Install **GitHub Desktop** and sign in with your GitHub account.
2. **Clone a repository** → choose **`aaronkelly-prem/Premrest`**. That downloads the folder to your Mac.
3. Open the **Claude desktop app → Claude Code → Open folder**, and pick the **Premrest** folder.

From then on, Premrest shows in your Claude Code workspace list. (Terminal alternative: `git clone` the repo, or ask Claude Code to clone it for you into an empty folder.)

## Keep the wall solid

When you open it, grant Claude Code access to the **Premrest folder only**, never a folder above it. That boundary is what stops Premrest ever seeing your personal or Queerfully Made files.

## Before the tools fully work

- **Gmail** — authorise the connector for the Premrest account (needed before email drafting).
- **Firmable** — paste your API key into the config (Claude guides you; it never handles the key).

Everything else is already built. Open the workspace and Claude leads with your open loops.
