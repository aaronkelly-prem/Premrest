# The weekly rhythm

Aaron blocks his week so nothing slips. Every loop and task is tagged to the day whose block it belongs to (`day:` field in `loops/open-loops.md`) so it surfaces in the right block instead of floating in a timeless pile.

| Day | Block |
|---|---|
| **Monday** | Admin, emails, team meetings, 1:1s |
| **Tuesday** | Flooring (Projects/Installs) partnership development + existing relationship management + sourcing speaking/presenting opportunities |
| **Wednesday AM** | Special Projects / Restoration partnership development |
| **Wednesday PM** | Cleaning FM & strata partnership development |
| **Thursday** | Podcast (Let's Talk Facilities) and marketing development |
| **Friday** | Finishing anything left unfinished from the week |
| **Floating** | Site/client visits, team training/education development |

## How the blocks work (important)

Blocks are set as **"Free"**, not "busy", in the calendar on purpose. They are **not hard holds** — things can be booked over the top. A block means: *if Aaron is in the office with nothing else booked, that is the work he does then.*

So Claude's job with the calendar (Full role):
- Know which block owns which work, and surface that block's themed loops when the block is open.
- Propose scheduling and draft invites that fit the rhythm; flag when something is landing on a block Aaron might want to protect.
- Never treat a block as immovable, and never send or book anything without Aaron (human gate).
